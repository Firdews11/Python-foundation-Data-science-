# Python Foundations Assignment
This repo contains my solutions for the Python Foundations assignment.

I picked different problems from each level and tried to keep the code simple and easy to understand.



## What I implemented

### Level 1
- Prime number checker  
- Factorial of a number  
- Reverse a string  

### Level 2
- Fibonacci sequence  
- Find the largest number in a list  
- Count vowels in a string  

### Level 3
- CLI Calculator  
- Tic-Tac-Toe game (CLI based)  


## About the programs

- The **calculator** lets you choose operations like add, subtract, multiply, and divide from the terminal.
- The **tic-tac-toe game** is a simple 2-player game you can play in the terminal using positions.
- The **prime checker** checks if a number is prime using a loop.
- The **factorial** is done using recursion.
- The **fibonacci** is also recursive and prints the sequence.
- Other programs are straightforward and do exactly what the task asks.
